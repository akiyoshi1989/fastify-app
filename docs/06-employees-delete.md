# 従業員削除 DELETE

## 目的

従業員 1 件を削除する `DELETE /employees/:id` を提供する。

## 対象外

- 楽観的更新
- 認証
- カスケード削除（関連リソースは無い）
- 呼び出し側 UI・クライアント実装

## パスパラメータ

| 名前 | 型 | 制約 |
| --- | --- | --- |
| id | 正の整数 | 詳細 GET と同じ |

## エンドポイント

| 項目 | 値 |
| --- | --- |
| メソッド | DELETE |
| パス | `/employees/:id` |
| 成功 | 200 |
| 成功ボディ | `{ "employees": {} }` |
| 未存在 | 404 |

成功時も他操作と同様に `employees` キーで包み、値は空オブジェクトにする。

### 失敗レスポンス

| 状況 | ステータス |
| --- | --- |
| `id` が正の整数でない | 400 |
| 該当従業員がいない | 404 |
| サーバエラー | 500 |
